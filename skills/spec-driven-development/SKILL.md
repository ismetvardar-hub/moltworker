# Spec-Driven Development

- Amaç, kullanıcı, başarı ölçütü
- Kapsam dışı + dokunulmaz bileşenler
- Veri/API sözleşmesi
- Test planı (`build` / `smoke` / `e2e`)
- ETHOS: kullanıcıya görünen metin tonu

Çıktı: onaylanabilir kısa PRD. Kod yok.
